GERADOR DE MILHARES — PROJETO ANDROID

1. Instale o Android Studio.
2. Abra esta pasta como projeto.
3. Aguarde a sincronização do Gradle.
4. Vá em Build > Build App Bundles or APKs > Build APKs.
5. O APK de teste ficará em:
   app/build/outputs/apk/debug/app-debug.apk

Para publicar na Play Store, use Build > Generate Signed Bundle / APK e gere um Android App Bundle (AAB) assinado.

O gerador funciona offline. A internet só é usada ao abrir o compartilhamento do WhatsApp.
